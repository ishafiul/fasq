# fasq_bloc example

Minimal Flutter app for trying the `fasq_bloc` adapter from this workspace.

## Run locally

From the repository root:

```bash
flutter pub get
flutter run
```

See the [package README](../README.md), [Bloc docs](https://shafi.dev/fasq/bloc),
and [repository issues](https://github.com/ishafiul/fasq/issues) for more.
