# Fasq core example

Minimal Flutter app for trying the core `fasq` package from this workspace.

## Run locally

From the repository root:

```bash
flutter pub get
flutter run
```

See the [core package README](../README.md), [Fasq docs](https://shafi.dev/fasq),
and [repository issues](https://github.com/ishafiul/fasq/issues) for more.
